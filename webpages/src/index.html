关于 Pocket Harness

Pocket Harness 是 DeepSeek Harness 的安卓客户端。 它在应用内运行一个内嵌的 Termux 快照与 Node 引擎，并向模型暴露安卓平台能力（无障碍、虚拟屏、通知、文件访问等）， 因此可以在手机上直接使用 DeepSeek Harness 的完整能力。

该下载哪个架构

目前仅提供 arm64（arm64-v8a / AArch64）版本，适用于 ARM64 安卓设备。
